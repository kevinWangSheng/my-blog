AI Engineer 频道的一支 7 分钟短 talk,Amol Kapoor 讲 Nori 怎么用 HTML/CSS 做 slides、docs,甚至做视频本身。它值得收进 links,不是因为「HTML is all you need」这句口号字面成立,而是因为它把一个常见误区讲清楚了:给 agent 的视觉工具,不该默认复刻人类拖拽画布的操作界面。

我在《HTML 不是网页,是 agent 的视觉中间表示》里完整拆了这支视频。最有用的 takeaway 是:如果目标是让 agent 稳定地产出可读、可改、可检查的视觉 artifact,先让它生成结构化、浏览器可渲染的东西,再导出图片、PDF 或视频。
