# ADR-0001: 单 agent + tools(不拆多 agent)

**状态**: 已采纳

**决策**: expense-agent 采用单 agent + tools 架构,不拆分为多 agent 编排。

**理由**: 发票抽取 + 入账建议是顺序依赖任务(OCR → 字段抽取 → 汇率换算 → 入账建议),子任务之间有强上下文依赖,不满足「子任务真独立可并行」的多 agent 启用条件。多 agent 在此场景成本约 15× 聊天 token,无对应价值。单 agent + tools 足以完成全流程,结构更简单、更易 eval、更易调试。

**改变此决策前须**: 出现真正可并行的独立子任务(如批量并发处理多张发票),且收益大于 15× token 成本;需先更新本 ADR 并经人审。
