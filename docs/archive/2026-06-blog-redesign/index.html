三套设计方向预览

同样的内容(首页 + 卡片 + 一段正文节选),三种明显不同的气质。点开任意一张全屏感受,挑你想要的方向。这只是预览,全站尚未改动。

A

克制 · 杂志感 · 浅色

Editorial Quiet

近单色暖白、大量留白、细排版、没有装饰渐变。像一本安静的文学刊物,信息靠层级而非框线分隔。
B

温暖 · 手札 · 浅色

Warm Garden

暖奶油 + 鼠尾草绿 + 琥珀。延续现在的纸感但更统一、更亲切,卡片柔和圆润,是“数字花园 / 自留地”的气质。
C

技术感 · 深色 · sans+mono

Modern Dark

近黑底 + 薄荷绿点缀 + 等宽字。代码优先、对比强烈,贴近 AI / dev 读者的现代技术博客气质。

字体通过 Google Fonts 在线加载(含思源宋体/黑体,解决中文显示)。预览页是独立 HTML,不属于项目依赖,也不会进入构建产物。
